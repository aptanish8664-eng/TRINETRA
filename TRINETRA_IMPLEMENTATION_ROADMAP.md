## Dependency and decision order

1. Complete Phase 0 and record evidence before implementation.
2. Resolve Phase 1 system dependency installation. No privileged install was attempted.
3. Validate one PX4 X500 completely before writing a production telemetry adapter.
4. Establish telemetry/data contracts, then wire UI to authoritative data.
5. Validate sensor algorithm and attack injection before dataset/model claims.
6. Validate one UAV and dataset/model behavior before adaptive PX4 response and scaling.
7. Keep Scenario Lab/AI/database/deployment work in isolated modules when independent; regression-test existing approvals, ownership, and user data.
8. Do not claim production PostgreSQL or remote simulation from local configuration alone.
