## Original local artwork

- `frontend/public/images/terrain-horizon.svg` — original TRINETRA vector illustration created for this project and used as a local fallback if the hero photo cannot load. It depicts stylized layered mountain terrain, contour lines, and abstract UAV silhouettes. It is not a photograph, satellite image, or geographic map.
- `frontend/public/logo/favicon.svg` — original eye, UAV, and sensor-iris emblem created for TRINETRA.
- `frontend/public/logo/trinetra-lockup.svg` — original wordmark lockup and emblem.
- Mission Control map marks, the 2D coordinate plane, and the Three.js terrain scene are generated from original SVG and Three.js geometry in the application.

No third-party video, terrain datasets, or UAV models are included. Lucide icons and the declared application dependencies remain package-managed software dependencies. The UI includes a system-font fallback if the optional web font request is unavailable.
